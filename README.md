
# Python Capstone Project: Walmart and Online Retail Analysis  
I did this capstone project as a part of my evaluation for a Data Analyst certification by IIT Madras, facilitated by Intellipaat.  
Project Objective:
This project focuses on sales forecasting and customer segmentation to optimize business operations for Walmart stores and an online retail dataset.  

Key Features:

Walmart Dataset:
Time-series forecasting using Prophet to predict weekly sales for the next 12 weeks.
Insights on sales trends, seasonality, and store-wise performance.
Online Retail Dataset:
Customer segmentation using RFM analysis and K-Means clustering.
Identification of high-value customers and actionable marketing strategies.  

Technologies Used:

Python (Pandas, Matplotlib, Seaborn, Scikit-learn, Prophet)
Data Preprocessing, Visualization, and Statistical Analysis  

Deliverables:

Predictive models for sales forecasting (RMSE and MAPE evaluated).
RFM-based customer segmentation with visualized clusters.
